# 复现与统计口径说明

本仓库的代码、权重与论文稿来自同一项目，但论文表格与当前数据目录在个别统计口径上存在差异，复现时请以这里为准。

## 参数量

- 论文表 2 / 表 4：最终模型 **2.60 M**。
- 本仓库 `weights/best.pt` 实测：**2.98 M / 7.83 GFLOPs**（含 ASF 分支的 `ScalSeq` / `Add`）。
- README 主表使用实测值；表 4 使用论文口径。

## 数据量

- 论文表 1：**2140 张图像 / 2962 个实例**。
- 当前 `dataset0224`：**2023 张 / 2941 个实例**（1378 训练 + 645 验证，验证集 1003 个实例）。
- 验证集逐类指标（论文表 3）与当前 645 张验证集一致。

## 指标轮次

- `results/ablation.csv`、`all_runs.csv` 取 `best.pt` 对应轮次（mAP50 最大），不是最后一轮。
- 最终模型 `exp34` 最佳轮次 226，早停于 276。

## 原始汇总表

- 项目根目录的 `all_experiments_metrics.csv` 把 `mAP50-95` 列误当成了 `mAP50`（所以 exp34 显示 57.43）。
- [`results/all_runs.csv`](../results/all_runs.csv) 已按 `results.csv` 重新计算。
